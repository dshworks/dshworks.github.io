dsh.works

The community workshop for DeepSeek Harness (dsh): verified field notes, a spam-filtered plugin registry, and theme discovery.

Not affiliated with DeepSeek. dsh is DeepSeek's agent harness; it lives at deepseek-ai/deepseek-harness and ships on npm as @deepseek-ai/dsh.

Start in 60 seconds

$ npx @deepseek-ai/dsh

dsh is a developer preview and the team promises breaking changes. Read the field notes before you hit the traps.

What lives here

  • howto-dsh Verified field notes: traps, skills, hooks, profiles. Every claim is dated against a specific dsh version, with source paths so you can re-verify it yourself.
  • awesome-dsh-plugins A spam-filtered, open-data plugin registry. plugins.json is the source of truth and the README is rendered from it; build on the JSON directly.
  • awesome-dsh-themes A registry of dsh themes and --dsw-* token skins, data-first like its sister registry.
  • deepseek-harness Upstream: the official harness itself. Start there for docs, releases, and the source of everything the notes here verify against.

Also in the org: handbook, an unofficial archive of link extracts and transcripts. It is private while it gets cleaned up for publication.

Shipping a plugin?

Tag your repo with the dsh-plugin topic. There is no official marketplace; that topic is the official discovery surface, and it is what the registry watches.
