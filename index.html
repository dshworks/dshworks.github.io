The dsh ecosystem, as data you can query

DeepSeek Harness ships no plugin marketplace, so the ecosystem lives scattered across a GitHub topic that anyone can post to. This sweeps that topic daily, checks each repo for a real install path, and publishes the result as JSON with a schema – every row carrying the date it was checked and the dsh version it was checked against. The lists are readable. The data is the point.

Why another list

  • 01

    Dated, or it does not count

    Every entry carries lastVerified and verifiedAgainst – the exact dsh release it loaded under. The harness is a developer preview that promises breaking changes and has already removed one manifest format with no migration. An undated “works with dsh” is a rumour.

  • 02

    The rejections are published too

    1,202 repos were swept and left out, each with a one-line reason in rejected.json. Rejections of judgment are permanent; rejections of fact carry a recheckAfter date and get swept again, so shipping a manifest late is not a life sentence. A list that hides its cutting-room floor is asking you to take curation on faith.

  • 03

    Themes you can actually see

    145 of 224 themes carry a real screenshot, and 39 ship a CSS override sheet that the gallery renders live – the dsh Web UI chrome, in the page, wearing that theme. Picking a skin from a repo name is guessing.

  • 04

    Notes that name the file

    howto-dsh documents the traps – dead manifest formats, patch layers that replace rather than merge, git installs that execute code outside any sandbox – and every claim cites a source path in the harness repo so you can re-verify it instead of believing us.

The plugin registry

awesome-dsh-plugins sorts 5,173 entries by form factor (bundle, plugin, skill, tool) and by 17 functional tags, with 584 installable straight from npm. The reef is the same registry as a filterable gallery.

The gate, in one line: a real install path – a dsh.bundle manifest, a published npm package, or a SKILL.md layout dsh actually discovers – not a renamed template fork. A scheduled sweep queues new finds for review; nothing enters the registry unreviewed.

The theme registry

awesome-dsh-themes covers ThemeRuntime packages, --dsw-* token overrides, and skins that restyle the dsh Web UI. Same schema discipline, same dated verification, plus previews. previewCss on an entry is what puts it in the live window.

The field notes

howto-dsh is what the registry data cannot tell you: how composition actually works, which tutorials are already wrong, and where the harness will bite. Everything is dated against a specific release, because nothing here is guaranteed past the version it was verified against – and the official docs are the place for stable reference.

What we ship ourselves

Two plugins, in the registry on the same terms as everyone else’s – same schema, same proof file, same verified-against date. Reading five thousand plugins taught us what was missing.

  • cost

    dsh-meter

    DeepSeek bills by the hour now. One line under the composer: what this session cost, which tariff is running, how long until it flips, and the balance behind it. Both published rate cards, priced at dispatch time. The site runs the tariff clock live.

  • unattended

    dsh-watch

    Background stream listeners that wake the agent: matching lines from a command or a growing file arrive as batched, budgeted notices – plus a daemon host, because no stock dsh surface keeps an agent standing.

Use it as an API

Open data, MIT, no key, no rate limit beyond GitHub’s own. The JSON is the source of truth; every README and gallery on this site is generated from it.

Shipping a plugin?

Tag the repo with the dsh-plugin topic. There is no official marketplace; that topic is the official discovery surface and it is what the sweep watches – so tagging is enough to be found, no PR required. If you want to land faster or fix a wrong row, open a PR against data/plugins.json; the README regenerates itself.

What this is not

  • Not official. dsh is DeepSeek’s agent harness, at deepseek-ai/deepseek-harness and on npm as @deepseek-ai/dsh. This site is community-run and unaffiliated; the harness README calls itself an idea and a showcase, and the ecosystem belongs to whoever builds in it.
  • Not a security review. An install path was verified, not a codebase. Git installs run code on your machine at install time, outside any sandbox – pin a commit, read the prepare script.
  • Not a quality ranking. Star counts are a dated snapshot of a repo’s popularity, carried so you can sort; they are not an opinion.
  • Not eternal. Preview software moves weekly. Anything checked against an older release is marked as such rather than quietly refreshed.

Start here: npx @deepseek-ai/dsh web brings the Web UI up on 127.0.0.1:3080. Then read the field notes before you hit the traps.
